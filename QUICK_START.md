# Quick Start Guide

## The app is starting! Here's what to do:

1. **Wait for the server to start** (look for "Metro waiting on..." message)

2. **Open your browser** and go to:
   ```
   http://localhost:8081
   ```
   (or whatever port it shows in the terminal)

3. **Press `w` in the terminal** to open web browser automatically

4. **You should see:**
   - "Best Vocabulary App" title
   - "If you see this, the app is working!" subtitle

## If you see a blank page:

1. Open Browser DevTools (F12)
2. Check Console tab for errors
3. Check Network tab - make sure `index.bundle` loads with status 200
